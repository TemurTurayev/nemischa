# Nemischa — инструкция для Claude Code

Открытый немецко-узбекский словарь A1–C1: датасет, сайт-тренажёр, колоды Anki.
Отвечай Темуру по-русски, коротко и по шагам. Интерфейс сайта — на узбекском (латиница).

## Как устроено

- `pipeline/` — Python (uv). `raw/*.json` → нормализация → ручные правки (`overrides.json`) →
  удаление повторов → сверка существительных с Wiktionary → `data/*.json`, `reports/qa.json`.
- `site/` — Astro 6 (не 7: ему нужен Node новее установленного 22.16). Страницы статические;
  тренажёр — чистый TypeScript в `src/trainer/`, прогресс хранится в localStorage.
- `site/src/lib/uz.ts` — все строки интерфейса. Пиши обычный апостроф, знаки ʻ и ʼ ставятся сами.
- Команды: `make data`, `make anki`, `make dev`, `make test`, `make e2e`.

## Правила

- Данные не править руками в `data/` — только через `pipeline/overrides.json` с полем `why`,
  затем `make data`. CI проверяет, что `data/` совпадает с выводом конвейера.
- Идентификаторы слов публичны (адреса страниц, ключи прогресса, заметки Anki). Они записаны в
  `pipeline/ids.json` и никогда не меняются и не переиспользуются. Файл руками не править.
- Повторы слова между уровнями не выбрасываются молча: новые значения приклеиваются к первой
  записи, все такие склейки видны в `pipeline/reports/qa.json` → `merged_translations`.
- В браузерном коде не использовать `innerHTML` (хук безопасности блокирует) — есть `src/lib/dom.ts`.
- Логика тренажёра — чистые функции в `site/src/trainer/state.ts`; `app.ts` только связывает их с DOM.
  После каждой перерисовки фокус должен оставаться на осмысленном элементе (`data-autofocus`),
  а экранный диктор получает текст через `#trainer-status`.
- Исходные PDF учебников и их OCR в репозиторий не добавлять: они защищены авторским правом.
- npm 10.9 падает при установке vitest без `--legacy-peer-deps`; `npm ci` из lock-файла работает.
- Проверка живого сайта теми же тестами:
  `E2E_BASE_URL=https://temurturayev.github.io/nemischa/ npx playwright test` (из `site/`).

## Уроки

- В CI Python берётся из `pipeline/.python-version` (3.12): у lxml 4.9 нет сборок под 3.13+.
- У `astral-sh/setup-uv` нет плавающего тега мажорной версии — указывать полную (`v10.3.3`).
- Не писать `update(f(state, await x))`: `state` читается до `await` и получается устаревшим.
  Сначала `const data = await x`, потом `update(f(state, data))`. Поймано только тестами по живому сайту.
